# MassMarket

Клиент-серверное мобильное приложение продуктового магазина.

## Состав проекта

- `app` — Android-клиент на Kotlin и Jetpack Compose.
- `server` — REST API на Ktor.
- `docker-compose.yml` — PostgreSQL и сервер.

## Быстрый запуск

1. Запустите Docker Desktop.
2. В корне проекта выполните `docker compose up --build`.
3. Откройте проект в Android Studio и запустите конфигурацию `app`.
4. Для эмулятора оставьте адрес сервера `http://10.0.2.2:8080`.
5. Для реального устройства укажите в настройках `http://IP_КОМПЬЮТЕРА:8080` (телефон и компьютер должны быть в одной сети).

API будет доступно по адресу `http://localhost:8080`, проверка состояния — `GET /health`.

## Демо-данные

Каталог из 12 товаров создаётся автоматически при первом запуске. Пользователи регистрируются в приложении. Пароли хранятся только как BCrypt-хеши, история заказов хранится в PostgreSQL и изолирована по пользователю.
